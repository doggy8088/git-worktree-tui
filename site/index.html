git worktree互動式切換指令

在終端機列出所有 worktree，用方向鍵選好，按 Enter 就切過去。

安裝

zsh · macOS、Linux

curl -fsSL https://gwt.gh.miniasp.com/install.sh | bash

PowerShell 7 · Windows

irm https://gwt.gh.miniasp.com/install.ps1 | iex

    一個儲存庫，
    多條工作目錄

    每個 worktree 各自對應一條分支，共用同一個 Git 物件庫。

    小，而且驗過

    每一個行為都有測試把關，包含在真的終端機裡送按鍵的互動測試。

    個執行期依賴，zsh 或 PowerShell 7 加上 git 就夠了

    常見問題

    獨立腳本跑在子處理序裡，它的 cd 只會影響自己，結束後你的終端機還在原地。只有載入目前 shell 的函式能改變工作目錄，所以 gwt 是一個被 source 的函式，不是執行檔（PowerShell 版則是用 Import-Module 載入的模組）。

    會顯示一個符合終端機高度的視窗，選取項目帶著它捲動，下方標示目前範圍。原本清單超過畫面高度時，游標上移會被終端機夾住，整段區塊會飄走，這個問題在 0.1.0 之後修掉了。

    目前支援 zsh 與 PowerShell 7（pwsh），其他都還不行。zsh 版用到 read -k 與從 1 起算的陣列索引，改寫成 bash 要換成 read -n 1 並重測游標行為，這件事在待辦清單上。PowerShell 版只支援 PowerShell 7，Windows 內建的 Windows PowerShell 5.1 不支援；在它裡面執行安裝腳本只會提醒你改用 pwsh，不會裝任何東西。

    不會。gwt 只讀清單、只做 cd，不執行 git worktree prune，也不刪任何目錄。要清掉失效的 worktree 請自己執行 git 的指令。

    設定都是環境變數：GWT_LANG 換中英文、GWT_NO_COLOR 關顏色、GWT_WIDTH 與 GWT_HEIGHT 指定選單尺寸、GWT_CLEAR_ON_EXIT 決定選完要不要擦掉選單、GWT_DIGIT_TIMEOUT 調整多位數編號的等待時間。PowerShell 用 $env:GWT_LANG = 'en' 這樣的寫法設定。

    zsh：再跑一次安裝腳本就是最新版——它會抓最新的 release，換掉 ~/.zsh/gwt.zsh，.zshrc 不必再動。要固定版本就在指令後面加 --version v0.1.0。

    PowerShell：同樣再跑一次 irm https://gwt.gh.miniasp.com/install.ps1 | iex，它會換掉 ~\.gwt\gwt.psm1，profile 不必再動。要固定版本就改跑 & ([scriptblock]::Create((irm https://gwt.gh.miniasp.com/install.ps1))) -Version vX.Y.Z；移除則把最後的參數換成 -Uninstall。
